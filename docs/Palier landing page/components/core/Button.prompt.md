A pill call-to-action with an optional arrow disc; use one per view as the primary action.

```jsx
<Button href="/home" variant="light" arrow>Try a free mock exam</Button>
```

variant: "light" (white pill, for photo grounds) | "dark" (deep teal pill, for paper grounds) | "link" (underlined text, secondary). `arrow` adds the 34px disc with ↗. `size`: "md" (16px) | "sm" (15px, no disc).
