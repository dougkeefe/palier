# ADR 12: MIT for code, CC BY 4.0 for content

**Status:** Accepted
**Date:** 2026-09-17
**Supersedes:** None

## Context

The project is open source and the item bank has independent reuse value. Code and content carry different reuse expectations.

## Decision

Code under MIT. Item bank and library content under CC BY 4.0. Derived passages additionally carry their source's terms, recorded per passage.

## Consequences

Positive: maximum reuse including by a department that wants to fork. Negative: a dual-licence repository needs its boundaries documented clearly or contributors will get it wrong.

## Revisit when

A source licence turns out to be incompatible with CC BY, in which case that passage is rewritten rather than the licence changed.
